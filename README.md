📡 "Load Balancing Algorithms for Communication Channels in Distributed Systems"
This repository contains the implementation and evaluation of selected load‑balancing algorithms applied to communication channels.
The project explores how heuristic and swarm‑based optimization methods can improve the distribution of traffic across network links, reducing bottlenecks and improving overall system performance.

The implementation includes:

graph‑based modelling of communication channels and flows,

integration of optimization algorithms (GA, AIW-PSO, ACOR) using the MEALPY framework,

custom modules for traffic generation, statistics, and scenario evaluation,

visualization of results and comparison of algorithm effectiveness.

The project was developed as part of an engineering thesis focused on practical, algorithmic approaches to load balancing in distributed environments.
